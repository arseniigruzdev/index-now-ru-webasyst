# Changelog

## 1.0.0 — 2026-07-28

- Первая версия для Shop-Script 12.
- Добавлена обработка официального события `product_save`.
- Публичный URL активного товара отправляется в
  `https://index-now.ru/api/v1/submit`.
- Добавлены настройки включения, API-ключа, ID сайта и тайм-аута.
- API-ключ хранится в зашифрованном виде и не попадает в журналы.
- Сетевые ошибки не прерывают сохранение товара.
- Добавлены английские исходные метаданные и русская локализация.\n- Лицензия архива приведена к LGPL-3.0-or-later, выбранной для бесплатного\n  продукта в каталоге Webasyst.
